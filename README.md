## 🔧 Setup & Deployment

### **Local Development**
1. Download or clone all project files
2. Ensure file structure is maintained:
   - `index.html` in root directory
   - `css/style.css` for stylesheets
   - `js/script.js` for JavaScript
3. Open `index.html` in a web browser
4. No server required - runs as static files

### **Production Deployment**
This website is ready for deployment on any static hosting service:
- **GitHub Pages**: Upload files to repository
- **Netlify**: Drag and drop folder to deploy
- **Vercel**: Connect repository for automatic deployment
- **Web Hosting**: Upload files via FTP/cPanel

### **Customization Guide**

#### **Wedding Information**
1. **Update Couple Names**: Search and replace "Arjun" and "Priya" in `index.html`
2. **Wedding Date**: Change date in `js/script.js` countdown function
3. **Venue Details**: Update addresses and phone numbers in `index.html`
4. **Event Schedule**: Modify dates and times in events section

#### **Images**
- Replace gallery images with your photos
- Update hero background image URL in `css/style.css`
- Ensure image dimensions are optimized for web

#### **Colors & Styling**
- Modify CSS custom properties in `:root` section of `style.css`
- All colors use CSS variables for easy theming
- Font families can be changed in Google Fonts link

#### **Form Integration**
- Replace localStorage demo in `js/script.js` with actual backend API
- Add email service integration (EmailJS, Formspree, etc.)
- Implement server-side validation and data storage
